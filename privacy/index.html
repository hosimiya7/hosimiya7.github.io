プライバシーポリシー

最終更新：2026年9月20日

English version

StellaDear（以下、「当方」）は、「Memoria」（以下、「本アプリ」）におけるユーザー情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

1. 収集する情報

当方は、本アプリの提供にあたり、以下の情報を収集・利用します。

  • アカウント認証情報（メールアドレス、またはApple／Googleアカウントによるサインイン情報）
  • 本アプリ内での会話ログ、カレンダーの登録イベント
  • キャラクターの設定、および関係性ステータス（記憶データを含む）
  • ユーザーが設定したキャラクター画像

2. 外部APIおよびサービスへのデータ送信について（重要開示）

本アプリは以下の外部サービスを利用しています。

Google Gemini API（Google LLC）
リアルタイムなキャラクター対話および記憶抽出ロジックの実現のために使用しています。ユーザーが入力したテキスト（会話内容およびカレンダーの予定等）は、暗号化された通信を通じて当該外部APIに送信され処理されます。送信されたデータがAIの公開学習データとして二次利用されないよう、適切なAPI契約を選択・管理しています。

TypeSafe AI（TypeSafe AI, Inc.）
会話の流れに関する判定（キャラクターの返答が特定の話題に触れたか、会話に関連する記憶はどれか 等）のために使用しています。判定に必要な範囲で、会話の内容（キャラクターの返答文・ユーザーの発言）、記憶データの一部、キャラクター名およびユーザーの呼び名が、暗号化された通信を通じて当該外部API（米国のサーバー）に送信され処理されます。当該サービスは文章を生成せず、判定結果（確率）のみを返します。同社のプライバシーポリシーにおいて、送信された入力はAIモデルの学習・ファインチューニングに使用されず、同社のサービス提供事業者以外の第三者に開示されないことが定められています。

Supabase（Supabase Inc.）
ユーザーデータ（会話ログ・記憶データ・カレンダー情報等）の保存・管理に使用しています。データは暗号化された状態でサーバー上に保管されます。

RevenueCat（RevenueCat, Inc.）
サブスクリプションのレシート検証およびプラン管理に使用しています。購入情報はApple/Google経由で処理され、RevenueCat社のサーバーを通じてプランの有効性が確認されます。

Firebase Cloud Messaging（Google LLC）
プッシュ通知の送信に使用しています。通知配信のため、デバイストークン（端末識別子）をFirebaseサーバーへ送信します。

Apple サインイン / Google サインイン（Apple Inc. / Google LLC）
アカウント認証に使用しています。サインイン時に、認証に必要な情報（メールアドレス等）が各社のシステムを通じて処理されます。

Google AdMob（Google LLC）
アプリ内の広告視聴によるエネルギー回復機能のために使用しています。当アプリはユーザーのトラッキングを行わず、非パーソナライズ広告（ユーザーの行動履歴に基づかない広告）のみを配信します。

Firebase Analytics（Google LLC）
アプリの利用状況（機能の利用有無・画面遷移等）を把握し、サービス改善のために使用しています。個人を特定する情報は収集しません。

3. データの利用目的

収集した情報は以下の目的にのみ使用します。

  • 本アプリのサービス提供および機能の改善
  • ユーザーサポート対応
  • 不正利用の防止

4. 第三者提供

当方は、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づく場合

5. データの削除（退会の権利）

ユーザーは、アプリ内の設定画面よりいつでもアカウントの削除（退会）を申請することができます。退会手続きが完了した時点で、サーバー上のユーザーデータは即座に物理削除されます。

Privacy Policy

Last updated: September 20, 2026

StellaDear ("we" or "us") sets out the following Privacy Policy regarding the handling of user information in "Memoria" ("the App").

1. Information We Collect

We collect and use the following information in connection with providing the App:

  • Account authentication information (email address, or Apple/Google account sign-in information)
  • Conversation logs and calendar events within the App
  • Character settings and relationship status (including memory data)
  • Character images set by the user

2. Third-Party APIs and Services (Important Disclosure)

The App uses the following external services:

Google Gemini API (Google LLC)
Used to power real-time character interactions and memory extraction logic. Text input by users (including conversation content and calendar events) is transmitted to this external API via encrypted communication for processing. We select and manage our API agreements to ensure that transmitted data is not used for public AI training.

TypeSafe AI (TypeSafe AI, Inc.)
Used to make judgments about the flow of conversation (such as whether a character's reply touched on a particular topic, or which memories are relevant to the conversation). To the extent necessary for these judgments, conversation content (character replies and user messages), portions of memory data, character names, and the name the user is called by are transmitted to this external API (servers located in the United States) via encrypted communication for processing. This service does not generate text; it only returns judgment results (probabilities). Under its privacy policy, input transmitted to the service is not used to train or fine-tune AI models and is not disclosed to third parties other than its service providers.

Supabase (Supabase Inc.)
Used to store and manage User Data (conversation logs, memory data, calendar information, etc.). Data is stored on servers in an encrypted state.

RevenueCat (RevenueCat, Inc.)
Used for subscription receipt validation and plan management. Purchase information is processed via Apple/Google, and plan validity is verified through RevenueCat's servers.

Firebase Cloud Messaging (Google LLC)
Used to deliver push notifications. Device tokens (device identifiers) are transmitted to Firebase servers for notification delivery.

Sign in with Apple / Google Sign-In (Apple Inc. / Google LLC)
Used for account authentication. Information required for authentication (such as email address) is processed through each company's systems at sign-in.

Google AdMob (Google LLC)
Used to power the in-app rewarded ad feature for energy recovery. The App does not track users and serves only non-personalized ads (ads not based on user behavior history).

Firebase Analytics (Google LLC)
Used to understand app usage (feature usage, screen navigation, etc.) for service improvement purposes. No personally identifiable information is collected.

3. Purpose of Use

Collected information is used solely for the following purposes:

  • Providing and improving the App's services and features
  • User support
  • Prevention of unauthorized use

4. Disclosure to Third Parties

We do not provide users' personal information to third parties except in the following cases:

  • With the user's consent
  • When required by law

5. Data Deletion (Right to Withdraw)

Users may request account deletion (withdrawal) at any time through the settings screen within the App. Upon completion of the withdrawal process, all User Data on our servers will be immediately and permanently deleted.
