# Memoria シンボル調整案

> **最新は `shelter/` の案Cです。** 囲みは「家・シェルター」の意味を担うというユーザーの説明を受け、外周なし案Aの推奨を撤回しました。以下は初回案の記録です。採用検討・書き出しには `shelter/README.md` を参照してください。

2026-09-05。ユーザー提供の `Group 320.svg` をもとに、SVGの輪郭を描き直したもの。画像生成は使用していません。

おすすめは **A：外周なし**。炎を手で包むモチーフと炎の3色は残し、手を細い輪郭線から生成りの塗りへ変えています。手の細かな曲線を減らし、親指と指先の間のすき間を整理。影・ぼかし・グラデーションをなくして、縮小したときの輪郭を安定させました。

比較用の **B：外周あり** も収録しています。Aと同じ手・炎を使い、外周のみ太い線にした案です。守られている感じは強くなりますが、小さい表示では線が増えるため、アプリ用はAを推奨します。

## 編集用SVG

| ファイル | 用途 |
| --- | --- |
| `memoria-symbol.svg` | A・おすすめ。暗い背景用のカラー版。背景透明 |
| `memoria-symbol-on-light.svg` | A・明るい背景用。手が夜の紺色。背景透明 |
| `memoria-symbol-mono.svg` | A・紺1色。明るい背景用。炎の内側は透明な切り抜き |
| `memoria-symbol-reversed.svg` | A・生成り1色。暗い背景用。炎の内側は透明な切り抜き |
| `memoria-symbol-outline.svg` | B・外周を太くしたカラー版。暗い背景用 |
| `memoria-symbol-outline-mono.svg` | B・生成り1色。暗い背景用 |
| `memoria-app-icon.svg` | Aを紺の正方形に配置したアプリ用原稿。1024×1024 |
| `original-reference.svg` | 比較用に保管した提供データのコピー |

通常のシンボルは256×256の座標で作成しています。拡大・縮小でき、SVGに対応する編集ソフトへ読み込めます。カラー版の炎は元データと同じ `#F29441` / `#D95D39` / `#F2C12E`。手は暗い背景で `#FFF8E8`、明るい背景で `#0C1524` です。

## PNGと比較画像

- `memoria-app-icon-1024.png`：紺の背景入り。角丸や影は含めず、正方形のまま書き出し。
- `memoria-app-icon-32.png` ～ `memoria-app-icon-512.png`：32 / 48 / 64 / 128 / 256 / 512pxの書き出し。
- `memoria-symbol-transparent-1024.png`：カラー版シンボル、背景透明。
- `comparison.png`：左が元データ、中央がA、右がB。64 / 48 / 32pxの縮小出力と単色版を掲載。
- `light-and-mono.png`：明るい背景・紺1色・生成り1色の確認用。

比較画像は表示側で縮小されることがあります。実寸を確認する場合は、各サイズのPNGを100%表示してください。32〜64pxの出力を確認していますが、実際のアプリやOSのアイコン一覧への組み込み確認は行っていません。

このフォルダはロゴ検討用です。サイトの文字ロゴやアプリ本体には自動で反映していません。

## 再書き出し

`build.mjs`にすべてのSVGパスと色をまとめています。Node.jsと`sharp`が利用できる環境で `node build.mjs` を実行すると書き出せます。`sharp`が通常のパッケージ検索先にない場合は、`MEMORIA_SHARP_PATH`にインストール先を指定してください。
